# ContractClarify AI
ContractClarify AI is a full stack document assistent which allows users to upload documents, ask queries in natural languages and receive citation-backed responses using RAG.

## Project Goal
This project aims to demonstrate full-stack engineering capabilities for AI-powered application, including FastApi,PostgreSQL, Rag, testing, Docker and documentation.

## Target Useres
- Users who need quick information retrival or verification based on documents such as policies, agreements, and contracts.

## Core Features
- User authentication
- PDF / TXT document upload
- Document text extraction and chunking
- Vector search using PostgreSQL and pgvector
- Citation-backed AI answers
- Query history
- Token cost tracking
- Logging and structured error handling
- Dockerized local development
- Backend tests and CI
